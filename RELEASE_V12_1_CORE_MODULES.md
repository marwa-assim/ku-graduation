# Version 12.1 — Core Module Responsive Upgrade

This release continues the presentation-only responsive programme and preserves existing business logic, routes, Supabase operations, roles, permissions and Kingdom University branding.

## Updated
- Users: mobile record cards, touch-friendly actions, responsive search and status controls.
- Organizations: improved responsive tenant cards, details and edit forms.
- Events: improved compact summaries, responsive editor sections and sticky save actions.
- Dashboard/shared pages: improved card stretching, action alignment and empty states.
