# KU Graduation Platform v9.2 — Student Ticket Cards

## Included
- Replaced raw QR token sharing with a professional ticket-card preview.
- Separate visual ticket card for Graduate, Free Guest, and Paid Guest tickets.
- Ticket card includes student name, student ID, event, configured date/time, venue, seat type, seat number, and one-time QR.
- Added ticket image download.
- Added email delivery with the ticket card attached as a PNG image.
- Added device file sharing for WhatsApp where supported; desktop fallback downloads the image before opening WhatsApp.
- Tickets remain student-only.
- Corrected Fitting and Photography source queries to load real student records rather than academic staff.

No SQL migration is required for this release.
