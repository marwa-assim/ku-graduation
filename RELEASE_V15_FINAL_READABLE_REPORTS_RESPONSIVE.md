# Version 15 Final — Readable Reports and Responsive Stabilization

## Readable operational exports
- Ticket report now exports participant name/ID, event, ticket type, seat number, readable ticket and booking numbers, status and entry information.
- Booking report now exports participant details, event, seats, payment status/provider/reference, totals and readable booking number.
- Audit report now resolves actors, participants, events and affected records into user-facing values instead of raw UUIDs.
- Services export now resolves event names.

## Responsive stabilization
Shared cards, page headers, forms, toolbars, modals, tables and status controls received a final responsive pass for mobile, tablet, laptop and wide desktop screens. Tables retain horizontal scrolling when required rather than breaking words or hiding controls.
